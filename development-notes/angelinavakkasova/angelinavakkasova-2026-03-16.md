# Дата: 2026-03-16

- **Что было сделано:** Продолжила работу над системой авторизации и связала основные страницы приложения в единый пользовательский сценарий: landing page → login / register → dashboard. Доработана архитектура авторизации через NextAuth с использованием mock-режима, чтобы не блокировать фронтенд-разработку до готовности backend. Настроена защита маршрута dashboard, добавлена server-side проверка сессии и redirect для уже авторизованных пользователей со страниц входа и регистрации. Отдельно был подключен и встроен готовый dashboard, разработанный Анной, в общий auth flow без изменения её UI-части. Также подготовлена конфигурация для OAuth-авторизации через GitHub и Google, созданы и частично настроены ключи и callback URL.
- **Проблемы:** Основные сложности возникли при подключении OAuth-ключей и настройке внешних провайдеров авторизации. Пришлось разбираться, какие redirect URI и callback URL нужны для Google и GitHub, чем отличается OAuth App от GitHub App, и какие значения должны быть указаны в env-переменных. Отдельная сложность в том, что backend от Юры ещё не готов, поэтому часть авторизации пока нельзя довести до полноценной интеграции с сервером. Лично для меня дополнительным фактором было то, что я только недавно смогла полноценно включиться в работу над проектом, потому что до этого болела и не могла уделять проекту достаточно времени.
- **Решения (или попытки):** Изучала документацию по NextAuth/Auth.js, настройке OAuth для Google и GitHub, а также по маршрутизации и server-side проверкам в Next.js. Чтобы не останавливать разработку, перевела auth flow на mock-first подход: все критические пользовательские сценарии можно тестировать уже сейчас без backend. Постепенно исправляла ошибки конфигурации, проблемы с callback URL, замечания линтера и организацию файлов. Для интеграции с dashboard был выбран безопасный вариант с разделением server-side проверки доступа и client-side UI-компонента. Также подготовлены понятные точки, куда позже будет вставляться backend Юры без полного переписывания текущей логики.
- **Мысли / Планы:** Следующим шагом нужно дождаться backend-контрактов от Юры и подключить реальную серверную авторизацию вместо заглушек. После этого необходимо окончательно проверить OAuth-вход через GitHub и Google уже в полном рабочем сценарии.  Дальше хочу перейти к следующей крупной части своей работы — разработке самой game practice / интерактивного тренажёра. Несмотря на то, что в проект я полноценно включилась не сразу из-за болезни, сейчас чувствую, что вошла в рабочий ритм и дальше работа пойдёт заметно быстрее и увереннее.
