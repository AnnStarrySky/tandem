## Description of My Work

I took on the role of both team lead and frontend developer. At the initial stage, I participated in choosing the tech stack and application architecture, organized the team’s workflow using a Kanban board, and set up the repository and collaboration processes.

The main part of my work was focused on developing the user interface using React and Next.js. I implemented core UI components (buttons, icons, header), the landing page, dashboard, and a dictionary component. I was also responsible for the application’s design: created the visual concept, selected the color scheme, and ensured interface responsiveness.

Additionally, I worked with routing (Next.js), internationalization (next-intl), and collaborated with the backend developer on designing the data structure. I implemented functionality for displaying learning progress and the user’s study plan.

During the process, I actively learned new technologies (React, Next.js, Ant Design), worked with documentation, and used AI tools as a supporting resource. The most challenging parts for me were understanding the component-based approach, organizing the application structure, and integrating various libraries.
