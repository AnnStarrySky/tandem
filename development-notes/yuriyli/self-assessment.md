### Роль в проекте: Fullstack.

### 1. Бэкенд инфраструктура проекта:

- Стек бэкенда: Выбран и реализован .NET (ASP.NET Core Web API) с поддержкой OpenAPI и интеграцией Swagger.

- База данных: Настроена SQLite через Entity Framework. Решены проблемы с хранением данных в Docker через Volumes. Настроен механизм миграций БД для контроля версий схемы.

- Backend & Docker: Освоена работа с Docker CLI на Ubuntu VPS. Настроена ручная публикация образов и запуск изолированных контейнеров для разработки (latest/dev).

### 2. Настройка Frontend-окружения:

- Настройка начальной конфигурации проекта на Next.js .

- Настройка линтинга и Git-хуков: ESLint, Prettier, Husky (запрет пуша в main, валидация названий веток, пре-коммит форматирование).

- Настройка Aliases для импорта компонентов.

- Установка UI-библиотек Ant Design и Tailwind CSS.

### 3. Реализация бэкенд-логики (API)

- Аутентификация и безопасность:

  - Реализована выдача и валидация JWT токенов на стороне .NET.

  - Настроена интеграция JWT с NextAuth.js на стороне фронтенда.

- Реализована валидация входящих моделей через встроенные атрибуты .NET.

- Документация моделей и статусов ответов API.

- CRUD:

  - Контроллер для Glossary компонента с поддержкой мультиязычности (RU/EN).

  - Контроллер Lessons с поддержкой мультиязычности (RU/EN).

  - Контроллер User для аутентификации/авторизации и поддержки компононента Settings (смена имени, пароля, email).

  - Пользовательская статистика: 

    - Разработаны POST/GET эндпоинты для сохранения и получения статистики по заданиям для авторизованного пользователя.

    - Эндпоинт для получения общего количества набранных пользователем очков и его позиция в рейтинге.

### 4. Frontend 

  - Компонент Loader (спиннер) для отображения загрузки .

  - Компонент ServerError для отображения ошибок API-запросов.

  - Глобальная страница Error для отображения необработанных исключений приложения.
