# Дата: 2026-03-22

- **Glossary.** Создал бекенд для словаря терминов. Задокументировал модели и возможные респонсы. Не уверен что это понадобится, но для меня было важно отработать процесс создания контроллеров. В дальнейшем будет проще на этом премере и можжно будет уделить больше внимания непосредственно нексту.

- **Авторизация.** Посмотрел модуль который сделала ангелина. Впринципе задача ясна, но мне необходимо согласовать с ней некоторые аспекты. Например вместо пороля разумней хранить сгенерированный токен. Еще отсутсвет id у модели пользователя, это создает проблему для обращения к БД. Логичней генерировать рандомный string id и с его помощью делать запросы в бд, это слабая но хоть какая-то защита от доступа к пользовательским данным. Полноценный обмен токенами можно либо отложить, либо отказатся для упрощения.

- **Миграция.** Совсем забыл добавить миграцию, для сохранения состояния Бд при изменениях это крайне желательная фича.

- **Планы.** Договорится о контроллере касательно аутентификации пользователя. Сам контроллер будет состоять всего из 3-4 методов, никакой сложности с этим быть не должно. Посмотрю по текущему чекпониту способ реализации, по-сути вопрос только в верстке самих страниц, статус загрузки можно оиспользовать стандартный.
